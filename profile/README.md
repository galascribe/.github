# Galascribe

**Sound like no one else.** Write clearly. Share insights that are unmistakably yours.

Galascribe is blog publishing software: a Markdown publishing platform for a site you own. You write a post, preview it, and publish it to your own domain; every post is a Markdown file in your own GitHub repository.

## What you get

- Scheduled posts, up to a year ahead
- Full-text RSS and Atom feeds
- Six built-in themes, each with light and dark modes
- Built-in search on your published site
- A visual editor with a Markdown view
- Your own domain with HTTPS, hosted on GitHub Pages
- Archive pages, tags and series
- An email newsletter, plus likes and comments
- Import from Substack, WordPress, Medium or Ghost

## Who it is for

Writers, creators and small teams who want an independent writing site or an author website they control. If you need to charge readers, install plugins, run a store or design pages by drag and drop, pick something else.

## How it works

1. Sign in with GitHub.
2. Galascribe sets up a repository you own.
3. Write and preview your posts.
4. Publish to GitHub Pages on your domain.

## Plans

Free is $0 for one site. Basic is $12 a month or $96 a year. Pro is $149 a month or $1,188 a year. [See pricing](https://app.galascribe.com/pricing).

## Open source parts

The renderer, schemas and publish tooling are Apache-2.0: [template](https://github.com/rathnasgala2/template), [schema](https://github.com/rathnasgala2/schema) and [publish](https://github.com/rathnasgala2/publish), in our engineering organisation [rathnasgala2](https://github.com/rathnasgala2). The Galascribe app is a hosted service.

## For creators on YouTube
